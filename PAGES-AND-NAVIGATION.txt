================================================================================
DATA FLOW DIAGRAM
================================================================================

New Student Flow:
1. Visit /oneform-home/ → View features and courses
2. Click "Apply Now" → /student-registration/ → Create account
3. Auto-login → Redirected to /application-form/
4. Fill form → Select colleges → Upload documents
5. Submit → Get application number + confirmation email
6. Check /my-applications/ → View status, download PDF
7. Make payment → /payment/ → Process fee
8. Receive final confirmation email

Admin Workflow:
1. Login to WordPress
2. Student Portal → Students (view registrations)
3. Student Portal → Services (manage offerings)
4. Student Portal → Lead Management (track inquiries)
5. Student Portal → Mock Tests (assign tests)
6. Student Portal → Test Generator (create tests)
7. OneForm → Applications (manage submissions)
8. OneForm → Payments (track transactions)

Service Pages (Data-Driven):
1. [ck_mega_menu] displays categories
2. User clicks category → Service pages load
3. Each page pulls content from /data/service-pages-content.php
4. CTA buttons link to dashboard or contact
