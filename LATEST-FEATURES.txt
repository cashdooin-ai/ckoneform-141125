HOW TO USE EACH NEW FEATURE
================================================================================

1. MOCK TESTS
   Admin Steps:
   a) Go to Student Portal → Test Generator
   b) Click "Create New Test"
   c) Select exam type (CUET/NEET/JEE/CAT)
   d) Add questions with options and answers
   e) Set marks and negative marking
   f) Save test
   g) Go to Student Portal → Mock Tests
   h) Assign test to students
   i) Set max attempts, due date, payment status

   Student Steps:
   a) Login to dashboard
   b) Look for "Take Test" section
   c) Click on assigned test
   d) Start test with timer
   e) Complete and submit
   f) View results and score
   g) Review questions with explanations

2. PAYMENT SETTINGS
   Admin Steps:
   a) Go to Student Portal → Payment Settings
   b) Select payment gateway (Razorpay/PayU/Paytm)
   c) Enter API credentials
   d) Set currency
   e) Save settings

   Payments are then automatically processed for:
   - Test access fees
   - Application submission fees
   - Service fees

3. LEAD MANAGEMENT
   Admin Steps:
   a) Setup lead capture form on website
      [ck_lead_capture_form] shortcode
   b) Students fill form with contact info
   c) Admin goes to Student Portal → Lead Management
   d) View all leads with filters
   e) Assign to team member
   f) Add notes and follow-up
   g) Change status (New → Contacted → Qualified → Converted)
   h) Export leads to CSV for external use

4. DASHBOARD CUSTOMIZATION
   Admin Steps:
   a) Go to Student Portal → Dashboard Settings
   b) Choose template (Modern or Classic)
   c) Pick theme color
   d) Toggle feature visibility
   e) Write welcome message
   f) Add announcement
   g) Save settings

   Students see customized dashboard next login

5. SERVICE PAGES
   No admin setup needed!
   a) Content defined in /data/service-pages-content.php
   b) Add [ck_mega_menu] to any page
   c) Categories and pages display automatically
   d) Users can browse and click CTAs
   e) Edit content in PHP file to customize
